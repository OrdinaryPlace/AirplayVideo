# AirplayVideo

Send a browser page or HDHomeRun channel to your selected Apple TVs.

Open **Web UI → Setup** to enable modes, find your tuner, pair TVs with their
on-screen PINs, and configure picture and sound. Use **Playback** for page/channel
selection and Play/Stop. Native Home Assistant entities use MQTT discovery.

An experimental independent C++/FFmpeg implementation for amd64 Home Assistant
OS/Supervised. Keep Protection mode enabled. See the Documentation tab for setup
and current compatibility limits.
